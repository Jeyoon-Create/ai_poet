## 🚀 다음 단계: GitHub에 업로드하기

### 빠른 시작 (3단계)

#### 1️⃣ GitHub에서 새 저장소 만들기
- https://github.com/new 방문
- 저장소 이름: `ai_poet`
- ⚠️ **"Initialize this repository with a README" 체크 해제**
- "Create repository" 클릭

#### 2️⃣ 로컬에서 명령어 실행
프로젝트 디렉토리에서 다음 명령어를 실행하세요:

```bash
cd ai_poet_project

# YOUR_USERNAME을 본인의 GitHub 사용자명으로 변경
git remote add origin https://github.com/YOUR_USERNAME/ai_poet.git

git branch -M main
git push -u origin main
```

#### 3️⃣ 완료!
GitHub에서 저장소를 확인하면 모든 파일이 업로드되어 있습니다.
